# Manual Testing

## Project Overview

This project demonstrates a structured manual software testing process
performed on a web-based e-commerce application.

## Application Under Test

SauceDemo

## Objective

To evaluate the functional behavior of the application's core
e-commerce workflows and identify defects through structured
and exploratory testing.

## Testing Scope

The testing will focus on:

- User authentication
- Product browsing
- Product sorting
- Shopping cart
- Checkout
- Navigation and session behavior

## Testing Approach

The project will include:

- Functional Testing
- Regression Testing
- Exploratory Testing
- UI Testing
- Negative Testing
- Test Design Techniques
