# ISTQB® Certified Tester Foundation Level (CTFL)

## Project Overview

This project documents my preparation for the ISTQB® Certified Tester
Foundation Level (CTFL) certification exam.

It combines theoretical study of the official CTFL syllabus with
practical exercises designed to apply and reinforce the concepts,
principles, and techniques learned throughout the certification.

## Objective

The main objective of this project is to build a strong foundation in
software testing and prepare for the ISTQB® CTFL certification exam.

The theoretical knowledge acquired during the study will be applied
through practical testing exercises, allowing me to connect ISTQB
concepts with real testing activities.

## Study Focus

The preparation covers the concepts and learning objectives defined in
the ISTQB® Certified Tester Foundation Level (CTFL) syllabus, including:

- Testing fundamentals
- Testing throughout the software development lifecycle
- Static testing
- Test analysis and design
- Test management
- Test tools

## Practical Application

To reinforce the concepts learned during the CTFL preparation, practical
testing exercises will be performed on a web-based e-commerce application.

### Application Under Test

**SauceDemo**

The application will be used as a practice environment to apply
appropriate testing concepts and techniques as they are covered during
the study.

## Practical Testing Activities

The practical work may include:

- Test analysis
- Test design
- Test case development
- Test execution
- Defect reporting
- Test documentation
- Exploratory testing
- Application of test design techniques

## Testing Scope

The practical testing will focus on core e-commerce workflows, including:

- User authentication
- Product browsing
- Product sorting
- Shopping cart
- Checkout
- Navigation and session behavior

The scope will evolve as new concepts are studied and applied.

## Learning Approach

The project follows the cycle:

**Study → Understand → Practice → Apply → Document**

Each practical exercise will be connected to the concepts covered in
the CTFL syllabus.
